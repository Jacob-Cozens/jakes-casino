# Project: Jake's Casino (BlackJack Simulator)

### Overview

This Project is called "Jake's Casino". In this project, I've created an app that allows you to play BlackJack! This project uses the Deck of Card API, which can be found [here](https://www.deckofcardsapi.com/).

This project was fairly difficult, and isn't as complete as I'd like it to be. Originally, I was going to do the backend of this project and make it more well designed as well, but I got my deadline dates mixed up and had to rush. Luckily, the project still showcases my ability to work with React and a third party API. It is fully functional and plays BlackJack perfectly! Feel free to pratice counting cards using this website, but don't tell anybody I told you that!

This game of BlackJack is soft 17 and uses six decks. Once you run out of cards, you will have to refresh the website.

**Project Features**

- React
- CSS
- BEM Methodology
- Flexbox
- Grid
- Routers
